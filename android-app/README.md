# Рыночные сигналы для Android

Нативное Android-приложение на Java. Введите тикер, чтобы загрузить дневные
котировки за шесть месяцев из Yahoo Finance Chart API и увидеть:

- последнюю цену и изменение за день;
- простые скользящие средние за 20 и 50 торговых сессий (SMA);
- RSI за 14 сессий;
- техническую оценку и объяснение факторов, на которых она основана.

Оценка описывает только исторические технические факторы. Она не является
рекомендацией купить или продать актив, не обещает доходность и не исполняет
сделки. Yahoo Finance может ограничивать или менять публичный интерфейс, а
котировки могут задерживаться или быть неполными.

## Сборка

Нужны JDK 17, Android SDK (API 35) и Gradle 8.9 или совместимый с Android
Gradle Plugin 8.7.3:

```shell
gradle -p android-app :app:assembleDebug
```

Для установки на подключённое устройство с настроенным Android SDK:

```shell
gradle -p android-app :app:installDebug
```
